# Roadmap de construcción priorizado

Orden recomendado: completar cada nivel antes de pasar al siguiente. Compilado desde los campos `priority` de los seis dominios.

## IMPRESCINDIBLE (must) — la base sin la cual no se siente completo

### Navegación e historial
| Conveniencia | Dominio | Por qué |
|---|---|---|
| Barra de direcciones tipo breadcrumb | Navegación | Seña de identidad; orientación constante |
| Editar y escribir ruta (Ctrl+L) | Navegación | Salto directo, pegar rutas, red |
| Autocompletado de rutas | Navegación | Escribir rutas sin fricción |
| Atrás y Adelante | Navegación | Modelo mental de navegador; restaura scroll/selección |
| Subir un nivel (Alt+Up) | Navegación | Movimiento jerárquico básico |
| Ir a Inicio | Navegación | Punto de partida por defecto |
| Panel de navegación en árbol | Navegación | Contexto y salto lateral |
| Acceso rápido / carpetas fijadas | Navegación | Acceso de un clic a lo frecuente |
| Pestañas de carpetas | Navegación | Multitarea esperada en Windows 11 |

### Selección y manipulación
| Conveniencia | Dominio | Por qué |
|---|---|---|
| Seleccionar todo / Deseleccionar | Selección | Operación elemental |
| Rubber-band, Ctrl+clic, Shift+clic | Selección | Los tres gestos de selección múltiple |
| Cortar/copiar/pegar | Portapapeles | Núcleo de mover/copiar; conflictos y progreso |
| Mover vs copiar al arrastrar | Arrastrar | Regla mismo/otro volumen + modificadores |
| Renombrar inline (F2) | Renombrado | Acción diaria; proteger extensión |
| Crear carpeta nueva (Ctrl+Shift+N) | Creación | Elemental |
| Eliminar a papelera / permanente | Eliminación | Reversibilidad + confirmación de lo irreversible |
| Deshacer y rehacer | Deshacer | Red de seguridad transversal |

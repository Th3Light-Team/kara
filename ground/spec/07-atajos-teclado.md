# Mapa maestro de atajos

Compilado desde los seis dominios, deduplicado y con conflictos anotados. Convención principal = Windows 11; variantes por explorador en *Contexto*. Los conflictos de teclado se marcan con ⚠.

## Navegación

| Atajo | Acción | Contexto | Visto en |
|---|---|---|---|
| Ctrl+L | Editar/enfocar la barra de direcciones como texto | Estándar de facto; también Alt+D y F4 en Windows | Windows, Dolphin, Nemo, Nautilus |
| Alt+D | Enfocar barra de direcciones | Alternativa Windows | Windows |
| F4 | Enfocar barra + desplegar historial de rutas escritas | Windows; en Dolphin F4 = terminal integrada ⚠ | Windows |
| Alt+Left | Atrás | Universal | Todos |
| Alt+Right | Adelante | Universal | Todos |
| Alt+Up | Subir un nivel (a carpeta padre) | Estándar recomendado, seguro en Windows y Linux | Windows, Dolphin, Nemo, Nautilus, Finder |
| Backspace | Atrás (Windows) ⚠ vs Subir (KDE/comandantes) | Elegir Atrás y dejar configurable | Windows / Dolphin / TC |
| Alt+Home | Ir a Inicio / carpeta personal (~) | Convención Linux adoptada como diseño (no es de Windows) | Dolphin, Nemo, Nautilus |
| XButton1 / XButton2 | Atrás / Adelante (botones laterales del ratón) | Universal | Windows, etc. |
| Alt+Down | Historial de carpetas del panel activo | Comandantes | Total Commander, Directory Opus |
| Ctrl+N | Nueva ventana | Cmd+N en Finder | Windows, Dolphin, Nemo, Nautilus |
| Clic central | Abrir carpeta en pestaña nueva (segundo plano) | Heredado de navegadores | Windows, Dolphin, Nemo, Nautilus |
| → / ← | Expandir / colapsar nodo del árbol (con foco) | Numpad * = expandir todo (Windows) | Windows, Dolphin, Finder |
| F9 | Mostrar/ocultar barra lateral | Alt+Cmd+S en Finder; Windows sin atajo | Dolphin, Nemo, Nautilus, Finder |
